# 🌐 Net Limit - Android Application Manager

Welcome to my very first official software project logged on GitHub! This repository is extremely special to me as it marks the absolute beginning of my software engineering journey.

## 🚀 About the Project
Net Limit is a lightweight Android utility designed to monitor data connections and manage network limitations for applications.
