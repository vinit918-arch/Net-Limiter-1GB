## 🚀 About the Project & Core Features

**Net Limit** is a powerful, system-wide network kill-switch designed to tackle phone addiction and manage data consumption in the **5G era**. Instead of managing individual apps, this manager acts as a master firewall that **shuts down the entire device's internet connection** instantly once the set threshold is breached.

With 5G offering unlimited and uncontrollable speed, children often get hooked on continuous streaming and gaming. This app serves as the perfect digital parenting tool to strictly enforce healthy screen time limits.

### 🔥 Key Features & Capabilities:

* **🛑 System-Wide Internet Lock:** No leaks, no loopholes. When the limit is hit, the app completely cuts off the internet for the *entire phone* using a secure internal VPN protocol.
* **🔄 Automatic Midnight Reset (12:00 AM):** Fully automated. Every night at exactly 12:00 AM, the data counter automatically resets to zero, kicking off a fresh data limit cycle for the next day without requiring any manual intervention.
* **📊 Single Unit Selection (MB or GB):** Simple and conflict-free UI. You can choose only **one** unit format at a time—either strictly set the limit in Megabytes (MB) OR in Gigabytes (GB). 
* **🔒 Built-in App Lock System:** High security to prevent smart workarounds. The app itself is locked, ensuring that children cannot enter the manager to alter or disable the set limits.
* **📈 Live Notification Tracker:** Displays real-time data usage statistics directly in the notification panel so parents can monitor ongoing usage at a glance.
* **👨‍👩‍👦 Ultimate Tool for Digital Parenting:** Specially tailored for family use. It effectively reduces children's screen time by physically removing the internet source, making it impossible to endlessly scroll or download on 5G.

## 📖 How it Works (User Guide)
1. **Secure the Manager:** Open the app and secure it with the built-in app lock.
2. **Choose Your Unit:** Select **either MB or GB** depending on your limit goal (the system locks the choice to one unit at a time to avoid errors).
3. **Set the Cap:** Input the total numerical data allowed for the session and activate the system.
4. **Automatic Lockdown:** The moment the data counter hits the selected limit, the background engine instantly drops the entire network connection.
5. **Fresh Start:** At 12:00 AM midnight, the app automatically resets the limit, restoring the internet for the next day's cycle.
